## Projeto em destaque — Resgate de Vidas

Um dos principais projetos que mantenho atualmente é o **Resgate de Vidas**, desenvolvido inicialmente como uma aplicação desktop em Python e utilizado também como parte do meu trabalho de conclusão de curso.

O projeto está passando por uma nova etapa de evolução, com a **migração da aplicação desktop para uma arquitetura web**, permitindo ampliar a acessibilidade e preparar o sistema para utilização em diferentes máquinas.

### Evolução atual do projeto

`Aplicação Desktop em Python` → `Aplicação Web com Django` → `PostgreSQL` → `Docker` → `Deploy`

A nova arquitetura utiliza tecnologias como:

- Python
- Django
- PostgreSQL
- Docker / Docker Compose
- Git e GitHub

Esse processo tem sido uma oportunidade para trabalhar não apenas com programação, mas também com **migração de sistemas, modelagem de dados, arquitetura, versionamento e implantação**.
